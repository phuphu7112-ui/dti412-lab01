
# Git Command Cheat Sheet

## Check Git Version
```bash
git --version
```
**Purpose:** Check the installed Git version.

## Configure Username
```bash
git config --global user.name "Your Name"
```
**Purpose:** Set your Git username.

## Configure Email
```bash
git config --global user.email "your@email.com"
```
**Purpose:** Set your Git email address.

## Display Configuration
```bash
git config --list
```
**Purpose:** Show Git configuration information.

## Clone Repository
```bash
git clone <repository-url>
```
**Purpose:** Download a GitHub repository.

## Check Status
```bash
git status
```
**Purpose:** Display the current Git status.

## Add Files
```bash
git add .
```
**Purpose:** Add files to the staging area.

## Commit Changes
```bash
git commit -m "Your message"
```
**Purpose:** Save staged changes.

## Upload to GitHub
```bash
git push
```
**Purpose:** Upload local commits to GitHub.

## Download Updates
```bash
git pull
```
**Purpose:** Download and integrate remote changes.

## View Commit History
```bash
git log --oneline
```
**Purpose:** Display commit history.

## Create Branch
```bash
git branch <branch-name>
```
**Purpose:** Create a new branch.

## Switch Branch
```bash
git switch <branch-name>
```
**Purpose:** Switch to another branch.

## Merge Branch
```bash
git merge <branch-name>
```
**Purpose:** Merge a branch into the current branch.
